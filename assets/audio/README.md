# Sound files

Every sound the game plays is a file here, named for what it does, in one folder per kind: `music/`, `sfx/`, `ambience/` and `footsteps/`. `src/data/musicTracks.js` lists the music (v318) and `src/data/audio.js` everything else; the code only ever asks for a sound by its id, so nothing else needs editing when a file changes.

## Replacing a sound

1. Save the new sound over the old file, with the same name. That is all.
2. Different format or name? Put it in the same folder and change its `file` (in `src/data/musicTracks.js` for music, `src/data/audio.js` for the rest). Any format the browser plays works; WAV, MP3 and OGG are safe choices (OGG loops most cleanly; MP3 adds a short gap at the loop point).
3. Too loud or too quiet? Change its `gain` in `src/data/audio.js` (0 to 1), or a music track's `volume` in `src/data/musicTracks.js`. The shipped files are normalized (their loudest moment at 90%) and `gain` sets how loud each plays in the mix, so a replacement mastered to a normal level sounds right at the same gain.
4. Music and ambient loops must loop: the end has to join the start without a click. Any length works; the shipped ones are 4 to 14 seconds.
5. Footsteps, birdsong and a few others play a little higher or lower each time (`vary` in `src/data/audio.js`), so one recording does not sound mechanical.

If a file is missing or the browser cannot decode it, the game plays that sound's built-in generated version instead (and says so in the console as a warning), so a broken file never makes the game silent.

## Where the shipped files come from

They are recorded from the game's own sound generators (`src/audio/sfx.js`, `music.js`, `ambience.js`, `footsteps.js`) by `tools/render_audio.mjs`: mono 22,050 Hz: 16-bit WAV for effects, ambience and footsteps, Ogg Vorbis for music (ffmpeg). Browsers that cannot decode Ogg play the same tunes from their generator recipes (`gen` in `src/data/musicTracks.js`), so nothing goes silent. Run it again after changing a generator (`node tools/render_audio.mjs hoe rain` re-records only those ids; with no ids it re-records everything, overwriting files you replaced by hand). It also writes each file's `gain`.

## Music

Ogg Vorbis. Every track is registered in `src/data/musicTracks.js` with what it is for: its category (the layer: menu, cutscene, event, boss, combat, fishing, special, location, season, default, or a stinger), location group, season, weather, time of day, festival or cutscene, priority, weight, volume and whether it loops. `src/systems/musicDirector.js` picks the right one for the moment (the most specific fitting track of the highest active layer) and `src/audio/music.js` crossfades to it. To add music, add a file here and an entry there; to replace a track, save over its file.
