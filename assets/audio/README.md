# Sound files

Every sound the game plays is a file here, named for what it does, in one folder per kind: `music/`, `sfx/`, `ambience/` and `footsteps/`. `src/data/audio.js` lists them all; the code only ever asks for a sound by its id, so nothing else needs editing when a file changes.

## Replacing a sound

1. Save the new sound over the old file, with the same name. That is all.
2. Different format or name (an `.ogg` or `.mp3`)? Put it in the same folder and change its `file` in `src/data/audio.js`. Any format the browser plays works; WAV, MP3 and OGG are safe choices (OGG loops most cleanly; MP3 adds a short gap at the loop point).
3. Too loud or too quiet? Change its `gain` in `src/data/audio.js` (0 to 1). The shipped files are normalized (their loudest moment at 90%) and `gain` sets how loud each plays in the mix, so a replacement mastered to a normal level sounds right at the same gain.
4. Music and ambient loops must loop: the end has to join the start without a click. Any length works; the shipped ones are 4 to 14 seconds.
5. Footsteps, birdsong and a few others play a little higher or lower each time (`vary` in `src/data/audio.js`), so one recording does not sound mechanical.

If a file is missing or the browser cannot decode it, the game plays that sound's built-in generated version instead (and says so in the console as a warning), so a broken file never makes the game silent.

## Where the shipped files come from

They are recorded from the game's own sound generators (`src/audio/sfx.js`, `music.js`, `ambience.js`, `footsteps.js`) by `tools/render_audio.mjs`: mono 16-bit WAV at 22,050 Hz. Run it again after changing a generator (`node tools/render_audio.mjs hoe rain` re-records only those ids; with no ids it re-records everything, overwriting files you replaced by hand). It also writes each file's `gain`.
